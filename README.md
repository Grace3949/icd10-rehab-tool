# 複雜復健給付查詢台

輸入 ICD-10-CM 代碼或病名，查官方中文對照與上下層相關代碼，並判定下列三項複雜復健治療能否開立：

| 支付代碼 | 項目 | 點數 | 基層院所 |
|---|---|---|---|
| 43030B | 複雜職能治療 | 600 | 43031C 500 ／ 43032C 360 |
| 44008B | 複雜語言治療 | 600 | 44012C 500 ／ 44009C 360 |
| 42014B | 複雜物理治療 | 600 | 42019C 500 ／ 42015C 360 |

線上使用：<https://grace3949.github.io/icd10-rehab-tool/>

## 功能

- **代碼查詢**　支援任意深度（`I63`、`I63.9`、`I63.011`、`S06.5X9A`），少打小數點會自動補正。
- **病名查詢**　中文、英文與臨床縮寫（CVA、TBI、SDH、CP、NPC、五十肩、斷指）。
- **相關疾病對照**　顯示該碼在 ICD-10-CM 樹上的上層分類、同層代碼與下層細分類，可點擊跳查。
- **條件判定**　依病人年齡、病程時序（住院中／出院後 3、6、12 個月）、手術時序逐條檢核適應症。
- **治療項目檢核**　OT / ST / PTC 項目勾選表，即時計算項目數與指定必含項目是否達標。
- **可申報標記**　依官方 USE 旗標區分「可申報代碼」與「分類標題」（後者不可單獨申報）。

## 資料來源

- 全民健康保險醫療服務給付項目及支付標準　第二部第二章第四節　復健治療（108.04.01 版）
- ICD-10-CM 代碼與中英文名稱：衛生福利部中央健康保險署　2023 年中文版 ICD-10-CM/PCS（1131118 V3）
- 編碼原則：ICD-10-CM/PCS 疾病分類編碼指引　2023 年版

## 代碼庫收錄範圍

官方 ICD-10-CM 工作表共 96,802 筆，本工具內嵌 33,638 筆：

- 落在 43030B／44008B 適應症範圍內之**全部 9,826 筆代碼（含 7 碼細分類）**
- 全書**三碼、四碼、五碼**層級代碼，供任意代碼對照

輸入未收錄之更細代碼時會回溯至最近上層顯示名稱；**給付判定一律以完整代碼直接比對規則清單，不受收錄範圍影響**。

## 已知模糊處

- 43030B 之 `S22.0-S32.0` 字面為跨章節區間，本工具依臨床意旨採計 S22.0 胸椎骨折與 S32.0 腰椎骨折，未納入 S23–S31。
- 44008B 之 `F480` 對應 ICD-10-CM F48.0，與同列其他兒童發展類代碼性質不同，申報前建議向分區業務組確認。
- 43030B 適應症 2（兒童中樞神經疾患）原文未列代碼，工具推定範圍見頁面「規則原文」面板。
- **42014B 複雜物理治療原文未列 ICD 代碼清單**，適應症為通則五之十九類臨床分類，其中第十、十六、十九類屬概括性分類。頁面內的代碼對照全屬工具推定，且 42014B 條文未明定治療項目數與時間下限，故不設門檻判定。

## 使用限制

本工具為臨床輔助檢核用，非官方申報系統。實際給付以健保署最新公告版本、分區業務組審查意見及個案病歷記載為準。

## 技術

單一自足 HTML 檔，無外部資源、無網路請求、無任何資料離開瀏覽器。下載後雙擊即可離線使用。需近幾年版本的 Chrome／Edge／Firefox／Safari。
